Capas

Aplicación web MVC para gestión de consultorios médicos. Manejo de pacientes, turnos, historias clínicas, vacunas, alergias, crecimiento, y más. Autenticación híbrida Firebase + ASP.NET Identity.

Arquitectura

Clean Architecture de 3 capas. PostgreSQL como base de datos, Redis como caché distribuido de 2 niveles.

┌─────────────────────────────────────────────────────────┐
│            🌐 Turnero (ASP.NET Core MVC Web App)        │
│  Controllers · Views · SignalR Hubs · JS Frontend       │
│  Excel/PDF Export · Bootstrap 5 · jQuery                │
└──────────────────────┬──────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────┐
│          ⚙️ Turnero.SL (Service Layer)                  │
│  Services (CRUD) · Repositories · Redis Cache           │
│  Firebase Auth · Logger · Cache Invalidation Pub/Sub    │
└──────────────────────┬──────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────┐
│          🗄️ Turnero.DAL (Data Access Layer)             │
│  EF Core DbContext · Models (13 entidades)              │
│  PostgreSQL (Npgsql) · Identity Framework               │
└─────────────────────────────────────────────────────────┘

Capas del Proyecto

Sistema de Caching

Caché distribuido de 2 niveles (L1: IMemoryCache local + L2: Redis compartido). Cross-instancia via Pub/Sub Redis.

┌──────────────┐     L1: IMemoryCache (ultra-fast, local)
│  Instancia 1 ├────► Cachea resultados en memoria
│  (App Web)   ├────► L2: Redis (distribuido, JSON)
└──────┬───────┘     Pub/Sub: invalida L1 en otras instancias
       │
┌──────▼───────┐
│    Redis     │
│ (7-alpine)   │
└──────┬───────┘
       │
┌──────▼───────┐     Fallback: si Redis no está disponible,
│  PostgreSQL  │     la app funciona solo con IMemoryCache
└──────────────┘     (graceful degradation)
